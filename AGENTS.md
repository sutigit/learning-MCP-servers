# Agent instructions

## The user writes the servers

The user is learning MCP by implementing the servers themselves
(`typescript/src/index.ts`, `python/weather.py`).
Guide and explain. Do not write the server code unless asked.

## Capturing learnings

When a lightbulb moment, gotcha, or surprising behavior happens
(MCP, TypeScript, Python), ask the user once if they want to
save it to [NOTES/README.md](NOTES/README.md).

- Ask at most once per insight. Skip trivial things.
- Save only if the user says yes.
- Entry: 1-2 sentences, fun tone, one emoji.
- Follow the format in the NOTES file. Put new entries
  at the top of the "Entries" list (newest first).
